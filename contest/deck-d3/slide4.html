정적 데모 고지
공모전용 데모는 서버 없이 동작합니다. 추천·안전·꽃말·이야기는 실제 엔진과 데이터를 쓰고, 카드 문구는 API 키를 노출하지 않기 위해 미리 검토한 예문을 씁니다. 이 차이를 숨기지 않고 화면에서 그대로 안내합니다.
