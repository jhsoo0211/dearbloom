## STEP 2 — 올리기 전에 로컬에서 확인

```powershell
npx serve out
```

브라우저에서 `http://localhost:3000` 을 열고 **§4.3 심사 동선**을 그대로 한 번 통과한다.

```text
랜딩
→ 추천 시작
→ 연인 / 화해 / 차분함 / 고양이 선택
→ 자유 서술 한 줄
→ 꽃 3안 확인
→ 추천 이유·이야기·안전 배지 확인
→ 메시지 수정
→ 구매처 또는 편지 화면 확인
```

> **자유 서술 시나리오 주의.** 자유 서술이 **결과를 바꾸는 장면**을 보여 주려면 **좋아하는 색을 고르지 말고** 자유 서술에만 「바닷가의 보라색 노을」을 적는다. 그러면 3안이 `흰 튤립 / 과꽃 / 재스민` → `흰 튤립 / 과꽃 / 글라디올러스` 로 바뀐다. 색 칩을 함께 고르면 결과가 그대로라 변화가 보이지 않는다(검증 기록 C-2).

확인이 끝나면 서버를 끈다(`Ctrl+C`).
