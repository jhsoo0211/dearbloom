# 드롭 데모 전 기능 감사 — 2026-08-18

`npm run build:static` 산출물(`out/`)을 그대로 띄우고 **모든 라우트의 모든 인터랙션을 눌러 본** 기록이다. 기준은 셋: **죽은 버튼 0 · 빈 자리 0 · 콘솔 오류 0.**

## 감사 방법

| 항목 | 내용 |
|---|---|
| 대상 | `out/` — 정적 드롭 데모 산출물(서버 없음). `npm run build` · `npm run build:static` 둘 다 exit 0 |
| 서버 | 의존성 0 의 정적 서버 **3400**(스크래치패드 `static-server.mjs`). ⚠ 3000 은 사용자 서버라 접속조차 하지 않았다 |
| 브라우저 | Playwright 1.62.1 + Chromium 1234 · `locale: ko-KR` · `timezoneId: Asia/Seoul` · 뷰포트 1280×900(기본)과 390×844(모바일 패스) |
| 라우트 | 11개 + 파생 2개(`/letter/studio` · `/r?c=` 조작본) |
| 회귀 | `npm run lint` · `typecheck` · `test` · `seed` 전부 exit 0 |
| 스크린샷 | `…/scratchpad/b1-b3/` (예시 상품 시트 · 읽을거리 카드 2종 · 편지 만들기/열기 · 모바일 내비 · 랜딩) |

**죽은 버튼을 재는 법.** 버튼마다 페이지를 새로 로드해 격리한 뒤, 누르기 전후의 **지문**(본문 HTML 해시 + 글자 수 + 모든 `aria-pressed`/`aria-expanded`/`aria-selected`/`open` 상태)을 비교했다. 지문도 주소도 그대로면 「죽었다」로 올리고, 올라온 건은 **전부 손으로 재검증**했다.

**빈 자리를 재는 법.** 글자도 그림도 입력칸도 없으면서 4px 이상 자리를 차지하는 `li·p·h1~h4·button·a·dd·dt·figcaption·td·th` 를 훑었다. `aria-hidden` 장식은 뺐다.

## 2. 자동 검출 6건은 **전부 오탐**이었다 (고칠 것 없음)

다음 감사에서 같은 것을 다시 올리지 않도록 남긴다.

| 자동 경고 | 재검증 | 실제 | 판정 |
|---|---|---|---|
| `/recommend` 「한 분께」 죽은 버튼 | 속성 확인 | `aria-pressed="true"` — **이미 켜진 칸**이다. 같은 화면의 꺼진 칸을 누르면 `false → true` 로 바뀐다 | 오탐 |
| `/groups` 「각각」 죽은 버튼 | 속성 확인 + 꺼진 칸 클릭 | `aria-selected="true"` — 이미 켜짐. 꺼진 칸 1개는 눌러서 켜졌다 | 오탐 |
| `/stories` 「전체 438」 죽은 버튼 | 속성 확인 | `aria-pressed="true"` — 필터의 기본값 | 오탐 |
| `/letter/studio` 「상아빛」 죽은 버튼 | 속성 확인 + 꺼진 칸 클릭 | `aria-pressed="true"` — 기본 테마. 꺼진 칸 4개 전부 눌러서 켜졌다 | 오탐 |
| `/` `a.db-card-hit` 12개 빈 자리 | 접근 이름 확인 | 378×768 카드 전체를 덮는 링크이고 이름은 `aria-label` 이 준다(`재스민 — 도감에서 보기`). 글자가 없는 것이 규격이다 | 오탐 |
| `/flowers/[slug]` `.shotDot` 2개 빈 자리 | 접근 이름·크기 | 44×44 아이콘 버튼, `aria-label="1번째 사진 — 붉은빛"`, 켜진 칸은 `aria-current="true"` | 오탐 |

> **자동 판정의 한계**: 「이미 켜진 토글」과 「죽은 버튼」은 DOM 지문만으로는 구별되지 않는다. 다음에도 이 여섯은 다시 올라올 것이므로, 올라오면 `aria-pressed`/`aria-selected` 부터 보라.

### 3-1. 추천 5걸음 완주 ×2

| 조합 | 걸음 | 결과 | 결과 화면 인터랙션 |
|---|---|---|---|
| 조합 1 (첫 선택지) | 1~5 전부 통과, 5걸음째 버튼이 `추천받기` 로 바뀜 | **흰 튤립** 외 3안 | 3안 세그먼트 6칸 · 색 칩 8칸(둘째로 바꾸니 `aria-checked=true`) · 멘트 톤 3칸 · **새로 받기 → 다른 문장이 옴** · 이야기 시트 열림→ESC 닫힘 |
| 조합 2 (두 번째 선택지) | 1~5 전부 통과 | **치자** 외 3안 | 세그먼트 7칸 · 색 칩 8칸 · 멘트 톤 4칸 · 새로 받기 → 다른 문장 · 이야기 시트 정상 |
| 연인 × 고백 (지정) | 1~5 통과 | **빨간 장미** | 「다른 문학도 보기」 → `다음 구절` 로 넘어가고 `앞 구절` 로 되돌아옴 |

- 「새로 받기」가 실제로 도는 것은 §1.5s ⑤ 의 데모 예문 변주(`message-variants.ts`)가 켜 준 것이다. `canReword` 가 데모에서만 켜지는 그 자리 그대로 확인됐다.
- 「이 결과 건네주기」는 클립보드 권한을 준 컨텍스트에서 **버튼 라벨이 `링크를 복사했어요` 로 바뀐다.** 권한이 없으면 아무 말도 하지 않는데, 그건 설계다(`handOver` 주석 — 취소를 성공처럼 말하지 않는다).
- 문학 발췌가 한 편뿐인 꽃에서는 「다른 문학도 보기」 자체가 서지 않는다(§1.5k "있을 때만"). 조합 1·2 가 그 경우였고, 여럿인 꽃(빨간 장미)에서 실제 동작을 따로 확인했다.

## 4. 콘솔·네트워크

**전 라우트·전 흐름에서 콘솔 오류 0 · 페이지 예외 0 · 4xx/5xx 응답 0.**

`build-static.mjs` 가 고치는 Windows 세그먼트 프리페치 경로 버그도 이번 빌드에서 그대로 돌았고(파일 **70개** 이름 교정), 그 덕에 클라이언트 라우터가 부르는 `__next.*.txt` 요청이 404 를 한 건도 내지 않았다. 이 교정이 빠지면 화면은 돌지만 콘솔에 404 가 쌓인다 — 그 스크립트의 머리말을 지우지 마라.

## 5. 남은 것 (이 감사에서 고치지 않은 것)

- **없음.** 올라온 6건이 전부 오탐이었고, 실제로 고친 것 한 건(읽을거리 각주의 조건부화)은 이 라운드 안에서 처리했다.
- ⚠ **찍은 시점을 밝혀 둔다.** 이 `out/` 은 같은 라운드의 다른 두 트랙(읽을거리 미리보기 이미지 · 도감 문학 블록)이 **아직 작업 중일 때** 뽑은 것이라, 그쪽 화면(`/reads`·`/flowers`·`/flowers/[slug]`·`/stories`)은 중간 상태를 담고 있다. 전 트랙이 합류하고 zip 을 다시 만들 때 그 네 줄만 한 번 더 훑으면 된다 — 이번 표의 나머지는 그대로 유효하다.
