## 2. 이번 배치의 방법 — 원문 raw 대조 원칙

배치 1의 함정 9건은 대부분 **“검색 요약이 잘못된 전제를 되확인해 주는”** 형태였다. 이번에는 그 실패를 구조적으로 막았다:

- **요약기를 신뢰 경로에서 뺐다.** 위키문헌은 `action=raw` 로 **위키텍스트 원본**을 받아 글자를 직접 대조했고,
  구텐베르크는 HTML 전문을 내려받아 정규식으로 해당 구절을 뽑았다. 검색 결과 요약문은 **후보 발굴에만** 썼고 적재 근거로는 쓰지 않았다.
- 이 방법이 실제로 함정 3건을 잡았다(§5).
- **WebFetch 요약기가 김소월 「진달래꽃」 전문 재현을 거부**(“저작권 있는 시”라며)한 사고도 있었다.
  PD 판정은 요약기의 몫이 아니므로 무시하고 `action=raw` 로 우회했다 — 요약기의 거부는 저작권 판정 근거가 아니다.

### 2-1. 번역 금지선 (배치 1 §2-2 승계, 이번 배치의 추가 위험 2건)

- **한국고전종합DB(ITKC)의 한국어 번역문** — 이황 매화시를 검색하면 DB 자체의 한국어 번역이 함께 노출된다.

- **향찰 해독문** — 「헌화가」의 “자줏빛 바위 가에…” 같은 한국어 본문은 전부 **20세기 학자(양주동·김완진 등)의 해독**이며 저작권이 살아 있다.

## 5. 이번 배치에서 잡은 함정 (배치 1 §2-4 이어서)

### 5-1. 🚨 「桐千年老恒藏曲, 梅一生寒不賣香」 — 출전 미확인으로 **기각**

매화 후보 1순위로 올라온 유명 대구다. 한국어 웹 전반이 **신흠(申欽, 1566–1628) 『야언(野言)』** 이라고 단언한다.
그러나 **한국고전종합DB에서 `梅一生寒不賣香` 검색 결과 0건**이다. 『상촌집』이 통째로 들어 있는 DB에서 0건이라는 것은
적어도 “신흠 문집 소재”라는 통설이 확인되지 않는다는 뜻이다.

게다가 검색 요약은 **“퇴계 이황이 이를 좌우명으로 삼았다”** 고 덧붙였는데, **이황은 1570년에 죽었고 그때 신흠은 네 살이었다.**
연대가 성립하지 않는다. 요약문이 스스로 무너진 사례이며, 배치 1이 경고한 함정의 교과서적 재현이다.

→ **적재하지 않았다.** 대신 출전이 확실한 이황 〈陶山月夜詠梅〉를 ITKC 정본으로 대조해 넣었다.

### 5-2. 두보 〈梔子〉 — `傷和` 가 아니라 **`相和`**

웹에 널리 도는 표기는 「與道氣**傷**和」다. 『광군방보』 권38 원문은 「與道氣**相**和」다.
뜻이 정반대로 갈린다(도의 기운을 *상하게 한다* ↔ 도의 기운과 *어울린다*). 판본 표기를 따랐고 `pd_basis` 에 남겼다.

### 5-3. 파킨슨(1629)에 **“Mournfull Widow” 는 없다**

스카비오사의 옛 영어 이름으로 널리 인용되는 ‘mournful widow’를 파킨슨에서 확인하려 했으나,
전문 검색 결과 `ournfull` **0건** · `ourning widow` **0건**이다. 파킨슨이 쓴 이름은 「Scabiosa rubra Indica / Red flowred Indian Scabious」다.
→ **‘mournful widow’ 를 파킨슨 출전으로 주장하지 않았다.** caveat 에도 쓰지 않았다.

### 5-4. 종 동정 판단 지점 4건 (전부 `caveat` 에 반영)

| 건 | 판단 |
|---|---|
| **『삼국유사』의 躑躅 = 철쭉** | 躑躅은 철쭉(*Rhododendron schlippenbachii*)이고 카탈로그 azalea 는 진달래(*R. mucronulatum*)다. **같은 속 다른 종.** 배치 1의 나데시코→카네이션·해당화→장미 선례를 따라 붙이고 caveat 로 밝혔다. (두견화=진달래는 맞지만, 이 대목의 글자는 두견화가 아니라 躑躅이라 그 논리를 쓸 수 없다.) |
| **김소월의 진달래 = 진달래** | **종 불일치 없음.** 카탈로그와 정확히 같은 종이라 caveat 는 종이 아니라 판본(1925년 옛 표기)과 지명(영변 약산)을 다뤘다. |
| **와틀 = 아카시아속 전체** | 고든의 wattle 이 은엽아카시아(*A. dealbata*)라고 특정할 근거는 없다. 영어 위키문헌 머리말도 “wattle trees are also known as acacia or mimosa”라고만 적는다. caveat 를 **‘와틀은 아카시아속을 두루 부르는 이름’** 수준으로 낮췄고, 동시에 `flowers.csv` 가 경고한 **신경초(*Mimosa pudica*)와 다른 나무**라는 사실을 같은 줄에 넣었다. |
| **파킨슨의 Limonium Rauwolfij = 스타티스** | 파킨슨은 이 풀을 **지치 무리(Buglosse)로 잘못 분류**했다. 그러나 묘사가 결정적이다 — ① 줄기에 “thin skinnes like wings”(날개), ② “made as it were of parchment”한 꽃받침이 마른 뒤에도 색을 지킴, ③ 그 껍질에서 흰 속꽃이 따로 나옴. 셋 다 *Limonium sinuatum* 의 진단 형질이며 자생지도 카디스·말라가(지중해)로 맞는다. 그래도 단정하지 않고 caveat 를 “맞아떨어져요” 수준으로 썼다. |

### 5-5. 판본 표기 판단 3건

- **『농가월령가』** — 위키문헌 본문은 특정 **필사본**이라 표기가 유별나다(‘면화 송니’, ‘고초로다’). 널리 인쇄되는 판본은 ‘고추 다래’로 끝나기도 한다.
  `pd_basis` 에 “필사본마다 표기가 갈린다”를 남겼다. 저작 연도는 위키문헌 머리말과 통설이 일치하는 **1816년**을 썼다.
- **임포 〈山園小梅〉** — 위키문헌 페이지의 품질 표시가 50%라 **본문 전체를 신뢰하지는 않았다.** 다만 적재한 두 구는
  같은 페이지가 밝힌 저본(『광군방보』 권23·『천가시』 권4)과 통행본이 모두 일치하는 부분이라 그 범위에서만 인용했다.
- **『삼국유사』 구두점** — 한문 원전에는 구두점이 없다. `text_original` 의 `，。：「」` 는 판본 편집자가 붙인 것이며 이 사실을 `pd_basis` 에 남겼다.

## 6. 옛한글 → 현대 완성형 옮김 대조표 (복원용)

### 6-1. 왜 옮겼나 (Advisor 결정 2026-08-18)

김소월·『농가월령가』 두 행의 `text_original` 은 원래 **옛한글 조합형 자모(U+1100 블록)** 로 적재했다.
그러나 이 글자들은 완성형 음절이 아니라 **조합형 자모**라, 글꼴이 받쳐 주지 않으면 두부(□)로 보이거나 자모가 분리돼 보인다.
Windows(맑은 고딕)는 대체로 서지만 **iOS·Android 한글 폰트에서 깨질 위험이 실재**하고 **모바일이 주 사용층**이다.
“일부 사용자에게만 깨지는 원문”은 원문을 지키는 것이 아니다. 옛한글 웹폰트 추가는 §1.3 외부 리소스 정책(허용 CDN 2곳)에 걸린다.
그리고 스키마가 이미 이 길을 마련해 두었다 — **“자체 현대어 표기이면 `translator=dearbloom`”**.

→ **현대 완성형 음절로 옮겨 적되, 바꾼 것은 철자(자모)뿐이다.** 어휘·어순·행갈이·종성은 한 글자도 건드리지 않았다.
두 행 모두 이미 `translator=dearbloom` 이었으므로 그 관례를 유지했다.

### 6-2. 옮김 규칙

**바꾼 것 — 렌더 불가 자모 2계열뿐:**

| 계열 | 원표기 | 옮김 | 근거 |
|---|---|---|---|
| 초성 합용병서 | `ᄭ`(U+112D 시옷기역) | `ㄲ` | 된소리를 적던 옛 표기 → 현대 쌍자음 |
| | `ᄯ`(U+112F 시옷디귿) | `ㄸ` | 〃 |
| | `ᄲ`(U+1132 시옷비읍) | `ㅃ` | 〃 |
| 아래아 | `ᆞ`(U+119E) | 문맥의 현대 모음 | `-ᄂᆞᆫ` → `-는` (관형사형 어미 관례) |
| | `ᆡ`(U+11A1 아래아이) | `ㅐ` | `ᄇᆡᆨ` → `백` |

**바꾸지 않은 것 — 옛 어형·옛 철자는 그대로 둔다:**
`내`(≠래) · `우리다`(≠오리다) · `거름거름`(≠걸음걸음) · `노힌`(≠놓인) · `츨`(≠을) · `삽분히`(≠사뿐히) · `즈려밟고`(그대로) ·
`셔풍`(≠서풍) · `갓튼`(≠같은) · `송니`(≠송이) · `고초`(≠고추) · 붙여쓰기 · 한자 `寧邊`·`藥山`.

> **종성 `ᆺ` 은 손대지 않았다.** `ᄭᅩᆺ` 은 `꽃` 이 아니라 **`꼿`** 으로 옮겼다 —
> 1925년 초판의 종성은 ㅊ이 아니라 ㅅ이고, ㅅ은 렌더에 아무 문제가 없어 바꿀 이유가 없다.
> ㅊ으로 고치면 렌더 수복이 아니라 **맞춤법 현대화**가 되어 `text_ko` 와 겹쳐 버린다.

### 6-4. 원표기 복원 방법

두 행 모두 `source_url` 이 **원표기를 그대로 보여 주는 페이지**를 가리킨다(위키문헌 원문난 / 필사본 전사).
`caveat` 에도 “초판(필사본) 그대로의 표기는 출처 링크에서 볼 수 있어요”를 한 줄로 넣어 화면에서도 안내한다.
프로그램으로 원표기를 다시 받으려면 요약기를 거치지 말고 위키텍스트를 직접 받을 것:

```
https://ko.wikisource.org/w/index.php?title=<제목 퍼센트인코딩>&action=raw
```

npm run seed      → 결과: 통과 (오류 0건), exit 0

자체 검증(파이썬 csv 파서로 재파싱):

|---|---|
| `quote_id` 유일성 (89행) | 중복 0 |
| `license=pd` 행의 `source_url` 전수 | 누락 0 |

> 퍼센트 인코딩 후 재확인하면 전부 200이다 — 다음 검증자가 같은 곳에서 헛발질하지 않도록 남긴다.
